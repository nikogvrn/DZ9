ymbol — символ для рисования.

2. запросить у пользователя радиус r и символ symbol.

3. запустить цикл for по оси Y сверху вниз: от 2 * r до -2 * r.

4. Внутри запустить цикл по оси X: от -3 * r до 3 * r.
Для каждой точки экрана (xScreen, y):

5. Перевести координаты в математические: x = xScreen / 2.0 (для компенсации вытянутости символов).

6. Вычислить значение уравнения окружности: circle = |x² + y² - r²|.

7. Вычислить значение уравнения ромба: rhomb = ||x| + |y| - √2 * r|.

8. Если точка удовлетворяет условию (circle <= r ИЛИ rhomb < 0.5), вывести symbol.

9. Иначе вывести пробел.
